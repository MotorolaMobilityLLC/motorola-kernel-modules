data: 16bits[16:31]
This is optional field depend on test purpose.

battery tcmd instance:
1. Primary battery FG reset
Devid = GLINK_DEV_BATT_ID_PRI = 1
Devtype = GLINK_DEV_TYPE_BAT = 0
Cmd = TCMD_BATT_FG_RESET = 0x66
Data = 0xXXXX
Tcmd = 0xXXXX6601

2. Set secondary battery cycle count to 100
Devid = GLINK_DEV_BATT_ID_SEC = 2
Devtype = GLINK_DEV_TYPE_BAT = 0
Cmd = TCMD_BATT_SET_CYCLE_COUNT = 0
Data = 0x0064
Tcmd = 0x00640002

Wireless RX/TX tcmd instance:
1. Enable/Disable WLS MCP VADP stepping
Devid = 0
Devtype = GLINK_DEV_TYPE_WLS = 3
Cmd = TCMD_WLS_STEP_VADP_ENABLE = 0
Data = 0: disabled，1: enabled
Tcmd =  enabled: 0x00010030，disabled: 0x00000030

2. Increase WLS MCP VADP
Devid = 0
Devtype = GLINK_DEV_TYPE_WLS = 3
Cmd = TCMD_WLS_STEP_VADP_INCREASE = 1
Data = optional
Tcmd = 0xXXXX0130

3. Decrease WLS MCP VADP
Devid = 0
Devtype = GLINK_DEV_TYPE_WLS = 3
Cmd = TCMD_WLS_STEP_VADP_DECREASE = 2
Data = optional
Tcmd = 0xXXXX0230

Pump charger IC tcmd instance:
1. enable/disable master charge pump IC
Devid = GLINK_DEV_ID_PUMP_MASTER = 0
Devtype = GLINK_DEV_TYPE_PUMP = 4
Cmd = TCMD_PUMP_ENABLE = 0
Data = enabled: 0x0001，disabled: 0x0000
Tcmd = enabled: 0x00010040, disabled: 0x00000040

2. Set work mode D2CP for master charge pump IC
Devid = GLINK_DEV_ID_PUMP_MASTER = 0
Devtype = GLINK_DEV_TYPE_PUMP = 4
Cmd = TCMD_PUMP_SET_MODE = 3
Data = NONE:0, D2CP:1, D4CP:2, 2X:3, 4X:4, PT:5
Tcmd = 0x00010340

3. Turn on/off ovpgate for master charge pump IC
Devid = GLINK_DEV_ID_PUMP_MASTER = 0
Devtype = GLINK_DEV_TYPE_PUMP = 4
Cmd = TCMD_PUMP_SET_OVPGATE = 4
Data = on: 0x0001，off: 0x0000
Tcmd = enabled: 0x00010440, disabled: 0x00000440

4. Turn on/off manual mode for slave charge pump IC
Devid = GLINK_DEV_ID_PUMP_SLAVE = 1
Devtype = GLINK_DEV_TYPE_PUMP = 4
Cmd = TCMD_PUMP_SET_MANUAL = 5
Data = on: 0x0001，off: 0x0000
Tcmd = enabled: 0x00010541, disabled: 0x00000541
